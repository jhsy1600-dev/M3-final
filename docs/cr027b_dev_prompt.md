# CR-027 보완 개발 지시서: 남은 옛 색 정리

작성: PM, 2026-11-23. 근거: `docs/cr027_report.md` §4(PM 결정 요청), 검증 `docs/cr027_verification.md`. CR-027 본 작업은 승인됨. 이 지시서는 **색만 바꾸는 작은 후속**이다. 이 작업만 한다.

## 1. 해야 할 일
`frontend/app/globals.css` 의 아래 규칙에서 옛 색을 **표의 새 값으로만** 바꾼다. 선택자·다른 속성은 건드리지 않는다. 테마 층(맨 끝 CR-027 블록)과 슬로건 규칙은 수정하지 않는다. 새 값은 모두 PM 이 대비를 계산해 확인한 것이다(4.5:1 이상 또는 비텍스트 3:1 이상).

| 선택자 | 옛 값 | 새 값 | 대비 확인 |
|---|---|---|---|
| `.mode-pill` | 배경 `#edf0ff`, 글자 `#4b56c8` | 배경 `var(--lav)`, 글자 `var(--blue-dark)` | 7.07 |
| `.mode-pill.edit-mode` | 배경 `#fff3dc`, 글자 `#93661e` | 배경 `#fff0dc`, 글자 `var(--orange)` | 5.30 |
| `.timer-panel` | 테두리·배경 `#e5e8f2` / `#fafbff` (원래 어느 속성에 쓰였는지 확인) | 테두리 `var(--line)`, 배경 `var(--white)` | 장식 |
| `.record-delete` | `#a45d66` | `var(--red)` | 8.38 |
| `.stat small` | `#a0a6b4` | `var(--muted)` | 5.30~5.52 |
| `.bar-label` | `#8991a3` | `var(--muted)` | 5.87 |
| `.mini-bars span` | `#c6ceff` | `var(--blue)` | 5.81(비텍스트) |
| `.mini-days`, `.scope-note`, `.goal-switch small` | `#778198` | `var(--muted)` | 5.87 |
| `.insight-copy > p` | `#555e73` | `#35445e` | 7.93 이상 |
| `.insight-copy > small` | `#8990a1` | `var(--muted)` | 5.00 |
| 전역 `ul`, `.modal ul` | `#586277` | `#35445e` | 9 이상 |
| 포커스 외곽선 | `#bdc7ff` | `var(--blue)` | 6.12 |

- `.mini-bars span` 에 상태별 변형(예: 비어 있는 날, 강조된 날)이 있으면 **서로 구별되는 상태를 유지**한다(한 색으로 합치지 않는다). 변형이 있으면 보고서에 적고 PM 결정을 기다린다.
- 표에 없는 옛 색(`#4b56c8` 계열, `#93661e` 등)을 이 작업 중에 더 발견하면 **바꾸지 말고 보고서에 목록으로** 적는다.

## 2. 하지 않을 것
JSX, 문구, 크기·간격·글꼴, 테마 층 블록, 슬로건, 새 색 만들기. 다크 모드.

## 3. 검증 요구
- `npm run typecheck`, `npm test`(기준 254건), `npm run build` 종료 코드 0. 테스트 수는 숫자로 보고한다.
- 새 테스트 1개: 위 선택자들에 옛 색 값이 남아 있지 않다(표의 옛 값이 `globals.css` 에서 해당 규칙에 없다). 기존 테스트가 옛 값을 확인하면 새 값으로 고치고 보고한다.
- 눈 확인은 못 하면 "미검증"으로 쓴다.

## 4. [필수] 완료 조건
- 보고서 `docs/cr027b_report.md`(변경 표, 발견한 추가 옛 색 목록, 테스트 수, 빌드 종료 코드, 미검증).
- **로컬 커밋만 하고 push 하지 않는다.** 개인 파일(`frontend/AGENTS.md`, 변경관리내역서 hwp·pdf, `docs/프롬프트와 응답사례연구.md`)은 커밋하지 않는다. 채팅에는 완료 여부, 테스트 통과 수, 빌드 종료 코드, 보고서 경로만 간단히 보고한다.
- 이 작업만 한다. 끝나면 멈추고 PM 검증을 기다린다.
