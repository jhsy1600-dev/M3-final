| 선택자 | 속성 | 옛 값 | 새 값 | 대비 |

- 표 밖에서 옛 색을 더 발견하면 바꾸지 말고 보고서에 목록으로 적는다.

- 보고서 `docs/cr027c_report.md`(변경 표, 테스트 수, 빌드 종료 코드, 미검증). **로컬 커밋만 하고 push 하지 않는다.** 개인 파일(`frontend/AGENTS.md`, 변경관리내역서 hwp·pdf, `docs/프롬프트와 응답사례연구.md`)은 커밋하지 않는다. 채팅에는 완료 여부, 테스트 수, 빌드 종료 코드, 보고서 경로만 간단히 보고한다. 끝나면 멈춘다.
