## 찍는 방법
- 브라우저 창 너비 1200px 이상(대시보드 슬로건이 보임), 확대 100%.
- 형식 PNG, 가로 1600px 안팎이면 충분합니다(너무 크면 저장소가 무거워짐).
- **개인정보 주의:** 학습 목표나 회고는 테스트용 내용으로 입력해서 찍습니다. 관리자 화면은 사용자 목록처럼 실제 사용자 정보가 보이는 화면을 피하고, 참고자료 관리나 사용자 피드백 중 개인정보가 없는 쪽을 찍습니다. 필요하면 가립니다.
- 발표 슬라이드의 "운영 화면 캡처" 빈칸(튜터 답변, 대시보드, 관리자 화면)에도 같은 캡처를 씁니다.
