## 규칙
- 개인정보가 보이는 캡처는 `images/manual/_비공개_` 로 시작하게 이름을 지으면 `.gitignore` 가 막아 저장소에 올라가지 않는다.
- 발표 슬라이드의 "운영 화면 캡처" 빈칸(튜터 답변, 대시보드, 관리자 화면)은 07, 09, 11번 캡처를 쓴다.
- 새 캡처를 붙일 때는 `사용자매뉴얼.md` 의 해당 자리에 `![설명](images/manual/NN_이름.png)` 를 넣는다.
