## 2. 기획 단계 이미지는 어떤 구성이었나 (유지할 것과 바꿀 것)
A 이미지(기획 단계): 제목 "AI 개인화 학습 페이스메이커" + 부제 → ① 학습자 경험 5단계 → ② 실행과 개인화(5단계 + AI 튜터 질문 흐름) → ③ 서비스 아키텍처(브라우저 → Next.js → FastAPI → Firebase Auth, Firestore, OpenAI, 고정 검토 자료) → ④ 핵심 데이터 관계(사용자 1:N 목표 1:N 과제 1:N 기록 1:0..1 회고) → ⑤ 기술 스택과 MVP 특징, "MVP 범위 밖" 띠.

## 4. A 이미지의 권장 구성 (5개 구역 유지 + 신규 띠)
1. **헤더:** "PaceMate · 서비스 구조 (구현 완료판)" 칩, 큰 제목 **"AI 학습 파트너"**, 슬로건과 한 줄 설명(아래 문구 그대로). 우측에 기존 일러스트처럼 학습자와 AI 로봇.
2. **학습자 경험(7단계):** ① 동의·익명 시작 ② 분야 입력과 직무 예시 ③ AI 과정·수준 추천 ④ 현재·목표 수준 선택 ⑤ 계획 초안 편집 후 확정 ⑥ 학습 실행(타이머·직접 입력)과 회고 ⑦ 인사이트·튜터 질문. 하단 띠: "분야·과정·수준은 AI 가 제안 · 수준은 분야별 서술형 이름 · 계획은 확정할 때만 저장".
3. **AI 가 일하는 방식(신규 구역):** 계획 3단계 호출(지침 → 설계 의견 → 과제 목록)을 화살표로, 그 아래 **"AI 는 제안하고, 서버가 검증하고, 계산은 서버가 한다"** 와 AI 튜터 흐름(질문 → 검토 자료 검색 RAG + 내 회고 Memory → 서버가 출처를 붙인 답변).
4. **서비스 아키텍처:** 브라우저 → Next.js·TypeScript(Vercel) → FastAPI·Python(Render) → Firebase Auth(익명 + 암호 이어쓰기) / Firestore(사용자별 데이터) / OpenAI API / 검토 자료(읽기 전용 + 관리자 승인). **관리자 영역**(사용자 관리·참고자료 수집·승인·사용자 피드백)을 같은 서버 위에 별도 상자로. 문장: "UID 는 인증 토큰에서만 정하고 본인 데이터만 조회합니다."
5. **핵심 데이터 관계:** 사용자 1:N 목표 1:N 과제 1:N 학습 기록 1:0..1 회고 + 목표 1:0..1 인사이트 + 사용자 1:N 대화 + 사용자 1:0..1 암호 정보. 옆에 "검토 학습자료(공용 읽기 전용) · 후보 자료(관리자 승인 대기)".
6. **구현 결과와 품질(신규 띠):** 자동 테스트 백엔드 1,393 · 프론트 262, API 48개, 사용자 피드백 36건 → 화면 변경 16건 적용, "개발팀과 검증 세션 분리 · 변경관리(CR)".
7. **기술 스택과 한계:** Next.js·TypeScript / FastAPI·Python / Firebase Auth + Firestore / OpenAI API / 배포 Vercel + Render / 버전 관리 GitHub. 하단 띠 **"아직 없는 것"**: Function Calling Agent · 사용자 자료 업로드 · 실시간 웹 검색 · Make 자동화 · 참고자료 보관함 · 능동 알림.
- 한 장에 다 넣기 어려우면 3번과 6번을 우선하고, 2번과 4·5번은 줄여도 된다. 중요도: 4 > 3 > 2 > 6 > 5 > 7.

## 5. 문구(그대로 쓸 것)
- 슬로건: **배움의 시작부터 완주까지, PaceMate가 함께합니다.**
- 설명: **목표 설정과 학습 계획부터 실행 기록, 회고, 검토된 참고자료, AI 튜터까지. PaceMate는 독학 학습자의 처음부터 끝까지를 함께하는 AI 학습 파트너입니다.**
- 부제(한 줄): **내 페이스로, 끝까지**
- 핵심 원칙 띠: "AI 는 제안하고, 서버가 검증하고, 계산은 서버가 한다" / "계획은 확정할 때만 저장" / "놓쳐도 실패나 연체가 아닌 추천 요일" / "수준은 분야별 서술형 이름".

## 6. 하지 말 것 (사실과 다르면 평가에서 문제가 된다)
- 구현되지 않은 기능을 넣지 않는다: Function Calling Agent, 실시간 웹 검색, 사용자 자료 업로드, Make 자동화, **푸시·이메일 알림**, 이메일·소셜 로그인, 멀티모달, **학습자용 참고자료 보관함(준비 중)**, 다국어, 시간 달성률 170% 표시.
- "모든 분야의 근거 자료가 있다"고 쓰지 않는다. 자료는 현재 IT·프로그래밍 분야뿐이다(자료가 없으면 근거 없음 표시).
- "AI 가 틀리지 않는다·정확하다"는 표현 금지. 사용자 수를 부풀리지 않는다(피드백 제공자 9명은 사용자 제공 값, 의견 36건은 사람 수가 아님).
- 개인 정보나 계정 ID, 키, 실제 사용자 데이터를 화면 예시에 넣지 않는다(가상 데이터만).
- 옛 이름 "AI 개인화 학습 페이스메이커", "AI 학습 코치", "AI 학습 플래너"를 쓰지 않는다(**"AI 학습 파트너"로 통일**). 영어 문구 "LEARN AT YOUR PACE"도 쓰지 않는다.
