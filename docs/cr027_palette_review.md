# CR-027 색상 기획안 검토 (PM)

작성: PM, 2026-11-23. 대상: 디자인팀의 "CR-027 색상 개편 기획안"(사용자 전달본, 파일 없음). 기준: `docs/cr027_design_brief.md` 2장 고정 규칙. 계산은 PM 이 직접 했다(WCAG 상대 휘도 공식, 색약은 Machado 2009 시뮬레이션). 이 단계는 **기획안(팔레트 제안)** 이고 브리프 4장의 결과물 3가지(수정 목업, 색 대응표, 전후 캡처)는 아직 제출되지 않았다.

## 1. 제안 팔레트
청록 중심: 강조 `#176B68`, 강조 어두운 톤 `#105653`, 옅은 강조 `#E5F3F1`, 배경 `#F3F7F6`, 본문 `#202A35`, 보조 글자 `#526273`, 테두리 `#D9E3E1`, 보조 포인트 `#7057A5`, 완료 `#247A57`, 경고 `#A85A12`, 오류 `#B42335`, 그림자 `rgba(27,54,53,.08)`.

## 4. 판정
**방향은 승인(조건부).** 청록 계열 팔레트와 대비 개선은 타당하다. **위 3장 1~3번의 보완안을 디자인팀에 요청하고, 4번의 결과물이 제출된 뒤에 개발 지시서(변수 정리 → 새 색 적용 2단계)를 낸다.** 확인하지 못한 것: 실제 앱 화면과 목업의 모든 색 조합, 반투명 배경 위의 글자, 휴대폰 폭에서의 모양, 발표 슬라이드 색과의 어울림(별도).

## 5. 디자인팀에 보낼 수정 요청 (요약)
1. 선택·활성(청록)과 완료(초록)를 구분하는 방법을 정해 달라(색 조정 또는 아이콘·글자 필수 규칙).
2. 적록 색약에서 완료와 오류가 구별되도록 오류색 또는 완료색의 명도를 조정해 달라(글자 대비 4.5:1 유지, 조정한 값의 대비표 포함).
3. 입력창·버튼 테두리는 3:1 이상으로 하고 카드 구분선과 구별해 적용 대상을 표로 적어 달라.
4. 브리프 4장의 결과물 3가지(수정 목업 복사본, 고유 색 전체 대응표, 전후 캡처)와 실제 앱 전용 클래스 목록을 제출해 달라.

## 6. 목업3(`mockup/archive/concept3_original_before_fixes.html`) 검토 (2026-11-23)
- **성격:** 원본 목업에 색을 덮어쓰는 `<style>` 블록(23줄, 규칙 77개, `!important` 사용)을 추가한 것이다. 색을 가린 비교에서 본문은 원본과 같고, 추가된 속성은 색(background, color, border-color, box-shadow, outline-color)과 색 변수뿐이다(배치·크기·글꼴·문구 변경 없음).
- **방향:** 청록이 아니라 **기존 파랑·보라 계열을 더 진하게** 한 안이다(`--blue #3155d9`, `--purple #743cc8`, `--bg #e9edf8`, `--green #18794e`, `--orange #b45309`, `--red #b42335`). 색 사이드바, 카드별 다른 면 색, 그라데이션이 특징이다.
- **통과:** 글자 대비 — 본문 13.27, 보조 글자 5.28, 파랑·초록·빨강·보라 on 흰색 모두 5 이상, 흰 글자 on 파랑 6.12·초록 5.41·빨강 6.50. 같은 규칙 안의 글자색·배경색 쌍 중 4.5 미달 0건.
- **보완 필요:** ① 경고색 `#b45309` 대 배경 4.29(4.5 미달) → `#a34a08`(5.07) 이상 ② 완료(초록)와 오류(빨강)가 색약에서 구별되지 않음(deutan 명도 대비 1.03) → 오류색을 `#8f1d2c`(초록과 1.63)처럼 어둡게 하고 아이콘·라벨 필수 ③ 파랑과 보라의 명도가 거의 같음(1.06) → 보라를 의미 구분에 쓰지 않거나 어둡게 ④ 입력창 테두리 대비 1.27~1.41 → 입력창·버튼만 `#7a87a8`(3.06 이상)로 진하게. 카드 구분선은 장식이라 현재 값 허용.
- **적용 방식 제안:** 덮어쓰기 블록은 `globals.css` 끝에 그대로 붙일 수 있다(실제 CSS와 목업의 클래스 119개가 같다). 실제 앱에만 있는 클래스(콤보박스, 튜터 말풍선, 동의 체크, 대화 목록)는 이 블록에 규칙이 없으므로 따로 추가해야 한다. 되돌리기는 블록 삭제로 끝난다.
